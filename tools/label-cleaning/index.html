快速复核并清洗 YOLO 数据集类别

直接读取本地文件夹中的图片与 .txt 标签（兼容平铺目录与 images/ + labels/ 结构），自动检测HBB / OBB 格式与所有 class_id。清洗时直接无损覆盖原 .txt，并在目录内生成label_cleaning_history.json 记录每个目标最近 3 轮的修改轨迹。

当前浏览器不支持 showDirectoryPicker（File System Access API），无法直接写回本地文件夹。建议使用Chrome / Edge / Arc 打开，或先点击下方按钮体验 Demo 模式。
或立即在线体验：
  • 左原图 · 右放大目标原图高亮当前目标位置，右侧将所有目标高清放大呈现，支持 OBB 自动旋正。
  • 无损覆盖 .txt仅替换第一列 class_id，100% 保留原有坐标小数精度与换行格式。
  • 近 3 轮清洗历史 JSON自动记录被改目标与最近三轮变更，随时按原/现类别筛选并一键定位复查。
